# ETF/종목 리스트 자동 업데이트 앱 (pykrx + KIS API 버전)

## 1. 로컬 최초 설정

```
python3 --version   # 3.10 이상 확인
pip install -r requirements.txt
```

## 2. KRX 로그인 설정 (2026-01-27부터 필수)

2026년 1월 27일부터 KRX 정보데이터시스템이 회원제로 전환되어, pykrx의 국내(1, 2번 시트) 함수를 쓰려면 KRX 로그인 정보(무료 회원 계정)가 필요합니다. 두 가지 방식 중 선택할 수 있으며, `app.py` 상단의 `USE_ENV_FILE` 값으로 전환합니다.

### 방식 A — .env 파일 (테스트/개인 사용 시 편리)

1. `app.py`의 `USE_ENV_FILE = True` 확인 (기본값)
2. `.env.example`을 복사해서 `.env`로 이름 변경

```
cp .env.example .env
```

3. `.env` 파일을 열어 실제 KRX 아이디/비밀번호, KIS App Key/Secret 입력

```
KRX_ID=본인아이디
KRX_PW=본인비밀번호
KIS_APP_KEY=본인KIS앱키
KIS_APP_SECRET=본인KIS앱시크릿
```

4. `.env`는 절대 GitHub 등에 올리지 마세요 (`.gitignore`에 포함되어 있음)

### 방식 B — 화면에서 매번 입력 (공유/배포 시 더 안전)

1. `app.py`에서 `USE_ENV_FILE = False`로 변경
2. 앱 실행 후 좌측 사이드바에 아이디/비밀번호, KIS API 키를 매번 입력 (저장되지 않음)

**테스트 완료 후 전환**: 테스트할 때는 A(.env)로 편하게 쓰고, 다른 사람과 공유하거나 배포할 때는 `app.py`에서 `USE_ENV_FILE = False` 한 줄만 바꾸면 B(화면 입력) 방식으로 전환됩니다.

## 3. 실행

```
streamlit run app.py
```

브라우저가 자동으로 열리며 `http://localhost:8501`로 접속됩니다.

2. 업데이트할 시트 체크

## 5. 데이터 소스 / 처리 방식

| 시트                      | 소스                              | 비고                                                                                  |
| ------------------------ | -------------------------------- | ------------------------------------------------------------------------------------ |
| 1. 국내 상장 ETF            | pykrx + KIS Open API             | 전종목 일괄조회(`get_etf_ohlcv_by_ticker`) 사용 — 종목별 반복호출 없음. 시가총액은 KIS API(`FHKST01010100`). 시가총액 내림차순 정렬 |
| 2. KOSPI200종목            | pykrx                             | 구성종목(`get_index_portfolio_deposit_file`) + 전종목 시세 + 배당수익률(`get_market_fundamental`). 시가총액 내림차순 정렬 |
| 3. 미국 상장 ETF 전체(상위100)  | TradingView 정적 페이지 스크래핑 + yfinance | 로그인 없이 AUM 기준 정렬 상위 100개까지 서버사이드 렌더링되는 걸 확인해 사용(2026-08-29). 100개 초과는 로그인 필요라 제외 |
| 4. 미국S&P500종목           | 위키피디아 + yfinance                | 종목별 개별 호출 (500종목, 시간 소요)                                                            |
| 5. 미국나스닥100종목           | 위키피디아 + yfinance                | 종목별 개별 호출 (100종목)                                                                   |
| 6. 미국 배당 ETF(SCHD)      | Schwab N-PORT 홀딩스표 + yfinance    | 종목별 개별 호출                                                                           |

## 6. TR/PR 관련 처리 방식

- **1번(ETF) 시트**: TR 6개월/YTD/1년 컬럼은 원본 구조 유지 목적으로 남겨두되, 값은 채우지 않음(빈칸). ETF는 상품 자체에 TR/PR 버전이 별도 상장된 경우가 많아 자동판별이 부정확할 수 있어 비워둠.
- **2, 3, 4, 5, 6번(개별종목/ETF) 시트**: 공식 TR 지수가 없으므로 컬럼명을 TR 대신 **PR**로 표기. `PR = 주가수익률`, 별도로 `최근 1년 배당수익률` 컬럼 제공. 필요 시 `PR + 배당수익률`로 TR 근사치를 사용자가 직접 계산 가능.

## 7. 종목코드 하이퍼링크

각 시트의 `종목코드` 컬럼은 클릭 시 해당 종목의 상세정보 페이지로 바로 이동하는 하이퍼링크가 걸려 있습니다. 시트 성격에 맞춰 가장 정보가 풍부한 사이트로 연결했습니다(2026-08-29 확인).

| 시트                    | 연결 사이트           | URL 패턴                                                       |
| ---------------------- | -------------------- | --------------------------------------------------------------- |
| 1. 국내 상장 ETF          | ETF CHECK (etfcheck.co.kr) | `etfcheck.co.kr/mobile/etpitem/{종목코드}/basic/개요`             |
| 2. KOSPI200종목          | 네이버증권             | `finance.naver.com/item/main.naver?code={종목코드}`               |
| 3. 미국 상장 ETF 전체(상위100) | stockanalysis.com    | `stockanalysis.com/etf/{티커소문자}/`                              |
| 4. 미국S&P500종목        | stockanalysis.com    | `stockanalysis.com/stocks/{티커소문자}/`                            |
| 5. 미국나스닥100종목        | stockanalysis.com    | `stockanalysis.com/stocks/{티커소문자}/`                            |
| 6. 미국 배당 ETF(SCHD)    | stockanalysis.com    | `stockanalysis.com/stocks/{티커소문자}/` (구성종목은 개별 주식이므로 stocks 사용) |

- 국내 ETF는 네이버증권 대신 ETF 전문 사이트인 ETFCheck을 채택(정보가 더 상세함).
- 미국 종목의 티커에 점(`.`)이 포함된 경우(예: `BRK.B`) yfinance 조회용으로 `BRK-B`처럼 하이픈으로 변환해 저장하는데, stockanalysis.com의 실제 URL 표기와 일치하는지는 소수 종목에 대해 별도 확인이 필요할 수 있습니다.

## 8. 한계 / 주의사항

- pykrx는 KRX/네이버 데이터를 스크래핑하는 비공식 라이브러리입니다. 사이트 구조 변경 시 일시적으로 오류가 날 수 있습니다.
- 국내 종목의 "1개월/6개월/1년 전" 가격은 정확히 그 날짜가 아니라 **가장 가까운 직전 영업일** 기준입니다.
- yfinance는 무료 API 특성상 간헐적 요청 실패가 있을 수 있습니다. 실패한 종목은 빈칸으로 남습니다. 오늘자 장중/미체결로 종가가 결측인 경우를 자동으로 걸러내도록 처리했습니다(2026-08-29 버그 수정).
- 미국 종목 500~600개(4, 5번 시트)를 순차 호출하므로 수 분 이상 걸릴 수 있습니다. 3번 시트(미국 상장 ETF 100개)는 시가총액을 TradingView 스크래핑값으로 대체해 yfinance의 무거운 종목정보 조회(`t.info`)를 생략, 상대적으로 빠릅니다.
- 3번 시트는 TradingView 정적 페이지가 로그인 없이 제공하는 상한(100개)까지만 반영됩니다. 그 이상(예: 200개, 전체)은 로그인이 필요해 이번 버전에서는 다루지 않습니다.
- KIS Open API는 "접근토큰 1일 1회 발급 원칙"에 따라 로컬에 `.kis_token_cache.json`으로 캐시됩니다(23시간 유효). 이 파일은 `.gitignore`에 포함되어 있어 GitHub에 올라가지 않습니다.
